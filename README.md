# «Новый рассвет» (New Dawn) — инкрементальная игра для Яндекс Игр

Космический кликер: добыча гелия-3 на планете Ксанта, отряды дронов, метеориты,
оффлайн-доход и престиж-цикл «Новая экспедиция» с путешествием по планетам.

Чистый HTML/CSS/JS, без сборки и зависимостей. RU + EN.

## Структура

```
new-dawn/
├── index.html          # разметка + подключение /sdk.js и модулей
├── css/style.css       # темы планет (CSS-переменные), анимации, адаптив
├── js/
│   ├── config.js       # постройки, вехи, планеты, тайминги, формат чисел
│   ├── i18n.js         # словари RU/EN, t(), случайные фразы

│   ├── vk.js           # мост VK Bridge (VK Игры на vk.com); активен только при window.vkBridge
│   ├── game.js         # ядро: экономика, вехи, метеорит, престиж
│   ├── save.js         # localStorage + облако, оффлайн-доход

├── yandex-games-annotation.md  # тексты аннотации для консоли

```

## Локальный запуск

Игра использует обычные скрипты (не ES-modules), но для чистоты запускайте
через HTTP-сервер (некоторые браузеры ограничивают `file://`):

```bash
cd new-dawn
python -m http.server 8080
# или: npx serve .
```

Открыть `http://localhost:8080`.

**Dev-режим:** `http://localhost:8080/?dev=1` — кнопки `+1e12`, форс метеорита,
форс престижа, сброс прогресса. Удобно для ручной проверки и модерации.
Дополнительно `?autostart=1` пропускает экран легенды, `?seed=mid` ставит сейв
«середина игры» (постройки, прогресс планеты ~50%), а `?offline=1` имитирует час
отсутствия (покажет отчёт офлайн-дохода) — всё полезно для скриншотов.

## Публикация — выбор платформы

Игра сама определяет платформу в рантайме (каскад мостов):

1. **VK Игры (vk.com)** — есть `window.vkBridge` → активен мост [`js/vk.js`](js/vk.js): облачные сейвы через VK WebApp Storage, реклама через `VKWebAppShowNativeAds` (interstitial/reward), язык из `VKWebAppGetClientInfo`. Лидерборд 🏆 скрыт (нет публичного web-API записи счёта).
2. **Яндекс Игры** — есть `window.YaGames` → активен мост [`js/sdk.js`](js/sdk.js): облако, лидерборд `total`, реклама.
3. **Локальная разработка / другой хостинг** — нет ни того, ни другого → бесшовная заглушка (реклама и облако «молчат», игра полностью играбельна).

Никаких правок в игровой логике не нужно — `NG.SDK` во всех случаях один и тот же интерфейс. Пошаговая инструкция для vk.com — в [`PUBLISHING-VK.md`](PUBLISHING-VK.md).

## Публикация в Яндекс Играх

1. **Консоль разработчика** — https://games.yandex.ru/console/ → «Добавить игру».
2. Загрузите файлы проекта (или подключите хостинг с HTTPS).
3. В настройках игры укажите:
   - **Тип:** HTML5-игра.
   - **URL:** адрес, где лежит `index.html`.
   - **Ориентация:** любая (игра адаптивна).
   - **Языки:** русский, английский.
4. **SDK:** в консоли выдаётся ссылка на `sdk.js` — в `index.html` уже стоит
   стандартный путь `<script src="/sdk.js"></script>`, который консоль отдаёт
   автоматически. Локально файла нет — мост [`js/sdk.js`](js/sdk.js) работает
   на заглушке.
5. **Лидерборд:** создайте лидерборд с именем **`total`** (метрика — суммарная
   добыча за всё время). Игра пишет скор автоматически при автосейве и престиже.
   Кнопка 🏆 в шапке открывает таблицу лидеров: топ-5 + записи вокруг игрока
   (запись игрока подсвечена). На локалке (заглушка SDK) показывается сообщение
   о недоступности лидерборда.
6. **Реклама:** interstitial показывается не чаще раза в 15 минут активной игры
   (настраивается в [`js/config.js`](js/config.js), блок `ad`). Показ обёрнут
   в `GameplayAPI.stop/start`.
7. **Облачные сохранения:** автоматически, с throttle 15 секунд + при уходе
   со страницы. Размер сейва ~1 КБ — лимит Яндекса не проблема.

## Механики (кратко)

| Механика | Формула |
|---|---|
| Цена постройки | `baseCost × 1.15^n` |
| Покупка пачкой | кнопка «Купить +10» — суммарная цена 10 шагов с ростом |
| Доход типа | `baseIncome × owned × множитель вех` |
| Тап по реактору | сила `(1 + уровень × 1 + 0.1 × построек) × бонус престижа`; апгрейд «Усилить тап» в карточке реактора, цена `⌊10 × 1.5^уровень⌋` |
| Вехи | 10/25/50 → ×2, 100/200 → ×3 (перемножаются) |
| Метеорит | раз в 3–7 мин, живёт 10 с, награда `max(60 × доход/с, 10)` |
| Оффлайн | 50% дохода, потолок 8 часов |
| Престиж | порог уровня по планете (1 млн → 100 млн → 1 млрд), очки `⌊накоплено/10⁹⌋` (мин. 1 за уровень), +2% навсегда за очко |
| Планеты | Ксанта → Эрвин → Тайга-9 → Муур (меняется только тема) |

Все параметры — в [`js/config.js`](js/config.js).

## Тон

Названия построек серьёзные, описания — с сухим юмором. Диспетчер — единственный
«персонаж»: аватар в углу экрана, комментирует события и периодически отпускает
реплики из пула в [`js/i18n.js`](js/i18n.js). Вокруг реактора кружат анимированные
воркеры — их число растёт с количеством построек. Без агрессивных таймеров
и исчезающих бонусов.
