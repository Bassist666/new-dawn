# Публикация «Новый рассвет» (New Dawn) в VK Игры (vk.com)

Игра уже адаптирована под VK Bridge:
- мост [`js/vk.js`](js/vk.js) активируется автоматически при `window.vkBridge`;
- облачные сейвы идут в VK WebApp Storage;
- реклама — `VKWebAppShowNativeAds` (interstitial / reward);
- язык определяется из `VKWebAppGetClientInfo`;
- лидерборд 🏆 скрыт (нет публичного web-API записи счёта);
- на других платформах и локально игра работает как раньше (Яндекс/заглушка).

---

## 1. Создание приложения

1. Войдите в ВКонтакте и откройте Кабинет разработчика: **https://dev.vk.com → «Мои приложения» → «Создать приложение»**.
2. Название — «Новый рассвет» (New Dawn), тип — **«Игра»** (Mini App / HTML5-игра).
3. В настройках укажите **платформу**: Браузерная версия (web).
4. Сохраните. Игра получит ID и ссылку вида `https://vk.com/app<ID>`.

## 2. Хостинг игры

VK запускает игру в iframe, поэтому нужен **HTTPS-адрес** до `index.html`:

- **GitHub Pages** — просто (ветка `gh-pages` / Actions);
- **Netlify / Vercel / Cloudflare Pages** — бесплатно, с HTTPS;
- любой свой хостинг с валидным HTTPS-сертификатом.

Не нужно ничего собирать — игра это статический HTML/CSS/JS.

## 3. Указание адреса в приложении

1. В кабинете приложения (раздел «Настройки») задайте **ссылку на стартовую страницу** (`index.html` на вашем HTTPS-хосте).
2. Сохраните и откройте игру по ссылке `https://vk.com/app<ID>` — внутри себя игра сама подхватит `vkBridge` скрипт (подключён с официального CDN `unpkg`), мост `js/vk.js` активируется сам — отдельно подключать ничего не нужно.

## 4. Что уже работает из коробки

| Возможность | Реализация |
|---|---|
| Облачный сейв | VK WebApp Storage (ключ = ключ localStorage игры, ~1 КБ < лимит) |
| Язык (RU/EN) | `VKWebAppGetClientInfo.language` |
| Локальное сохранение | localStorage как и раньше |
| Rewarded-реклама (энергия, буст ×2) | `VKWebAppShowNativeAds` `ad_format: 'reward'` |
| Межстраничная реклама | `VKWebAppShowNativeAds` `ad_format: 'interstitial'` (раз в 15 мин, как и раньше) |
| Dev-параметры | `?dev=1`, `?seed=mid`, `?prestige=1`, `?autostart=1` работают |

## 5. Реклама — активация

1. В настройках приложения VK включите **монетизацию / рекламу** для мини-приложения.
2. Rewarded-формат открывается после публикации и проверки (как и на Яндексе).
3. Если реклама недоступна/не настроена — игра не ломается: мост аккуратно возвращает «не показано», кнопки «Смотреть» вежливо сообщают об этом (как на локальной заглушке).

## 6. Лидерборд 🏆

В VK-версии лидерборд **выключен**: у VK нет публичного web-API «записи счёта» без серверной части, поэтому кнопка 🏆 скрыта автоматически (проверяется флаг `NG.SDK.vk`). На Яндексе и локально кнопка работает как раньше.

✅ Если лидерборд в VK всё же критичен — нужна серверная интеграция:
- VK Bridge: `VKWebAppGetLeaderboard` (работает по настроенному лидерборду приложения) или
- рейтинги сообществ (`VKWebAppGetCommunityRates`) — обычно делается отдельной серверной частью на бэкенде игры.

## 8. Проверка перед публикацией

1. Залейте файлы на HTTPS-хостинг, откройте `https://vk.com/app<ID>`.
2. В консоли браузера не должно быть критичных ошибок (кроме ожидаемого 404 на `/sdk.js` — это путь Яндекса, на VK он не нужен и безвреден).
3. Проверьте: легенда → старт → покупки → метеорит → офлайн-отчёт (перезагрузка) → престиж (`?prestige=1`) → rewarded (`?dev=1`).
4. Убедитесь, что в VK-версии кнопки 🏆 нет, а на Яндексе/локально она есть.
5. Сбросьте свой прогресс кнопкой «Сброс» на dev-панели и убедитесь, что воркеры вокруг реактора исчезают.

## 9. Публикация в каталог

`Кабинет разработчика → приложение → Модерация / Публикация`:
- заполните описание (тексты из раздела 7), иконку (уже есть `icon-512.png`), скриншоты (16:9/9:16 из `screenshots/`);
- категория: «Казуальные / Инкрементальная»;
- возрастное ограничение: 0+;
- отправьте на проверку. После одобрения игра попадает в каталог VK Игр.

## Требования сборки к VK (проверено по коду)

- скрипт VK Bridge подключён с официального CDN: `https://unpkg.com/@vkontakte/vk-bridge/dist/browser.min.js`;
- все методы моста обёрнуты в try/catch и Promise-деградируют — платформа не блокирует запуск;
- файлы для хостинга: `index.html`, `css/style.css`, `js/*.js`, `icon-512.png` (без `screenshots/`, `server.log`, `.md`).
